# Global Navigation Keyboard Shortcuts

TrusTrove supports fast global navigation via single-key shortcuts when working outside form inputs and textareas.

## Available Shortcuts

- `D`: Navigate to Dashboard (`/dashboard`)
- `I`: Navigate to Invoices / SME Console (`/sme`)
- `M`: Navigate to Marketplace (`/marketplace`)
- `L`: Navigate to Liquidity Provider (LP) Pool (`/lp`)
- `S`: Navigate to Settings (`/settings`)
- `H`: Navigate to Help (`/help`)

## Accessibility and Customization

- **Input Safety**: Shortcuts are automatically disabled when typing in any `input`, `textarea`, `select`, or contenteditable element.
- **Browser / AT Safety**: Shortcuts do not override standard browser shortcuts or assistive technology keys (modified keypresses such as Ctrl/Cmd/Alt/Shift are ignored).
- **Settings Toggle**: Users can completely disable keyboard shortcuts from the **Settings** page (`/settings`).
